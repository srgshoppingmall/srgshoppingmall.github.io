# SRG Shopping Mall | এসআরজি শপিং মল

একটি অনলাইন মার্কেটপ্লেস, যেখানে ক্রেতা বিভিন্ন সেলারের পণ্য ক্যাশ অন ডেলিভারিতে অর্ডার করতে পারেন।
An online marketplace where buyers can order products from many sellers with cash on delivery.

## অ্যাপ ইনস্টল করুন | Install the app

ফোনের Chrome-এ খুলুন: https://srgshoppingmall.github.io/user.html
তারপর মেনু (⋮) থেকে **Install app** বা **Add to Home screen** চাপুন।

Open the link above in Chrome, then use the menu (⋮) and choose **Install app** or **Add to Home screen**.
